INTRAK User Manual
Internship & OJT Tracking and Management System — complete role-based guidance for students, instructors, coordinators, industry partners, and administrators.
Version 2.0 Manual 2026.03 5 User Roles
What INTRAK Does
INTRAK centralizes all internship operations into one integrated platform for all stakeholders.
Documents
Submit, review, and track all required internship documents by phase.
Company Placement
Browse, apply, and track placement at partner companies.
Attendance
Log and verify attendance with hour tracking and exports.
Evaluations
Partners submit evaluations; students view their results.
Reports
Program-wide compliance and operational reporting.
Notifications
Role-based alerts for all workflow actions and submissions.
User Roles
Student/student
Submits documents, applies to companies, logs attendance, views evaluations
Instructor/instructor
Reviews docs, applications, proposals; monitors assigned students
Coordinator/coordinator
Oversees entire program, companies, announcements, and reporting
Industry Partner/industry-partner
Verifies attendance and submits intern performance evaluations
Admin/admin
Manages platform settings, users, maintenance, and system controls

Account Security
Security & Account Settings
Authentication model, two-factor authentication, email verification, and profile photo management.
Security Features
Role-based route protection
All portal routes are guarded — unauthorized users are redirected to login. Access and refresh token session model.
Always On
Two-Factor Authentication (2FA)
Enable/disable from account settings. Login challenge with one-time code. Backup code verification and regeneration supported.
Optional
Email Verification
Send and verify account email via token workflow. Check verification status inside account settings.
Recommended
Profile Photo Management
Upload, replace, or remove your photo. Updates are reflected across all portal header and profile panels.

Troubleshooting Guide
Common issues and step-by-step resolution paths for all user roles.
!
Cannot Log In
Confirm correct email and password are being entered
Check if your account is still active
Use /forgot-password if you've forgotten your password
Contact the admin if the issue persists
!
Did Not Receive Verification or 2FA Code
Check your spam or junk mail folder
Wait a moment, then use the resend option
Confirm your registered email address is correct
!
Document Upload or Submission Fails
Verify file type and size meet policy requirements
Retry on a stable internet connection
Check if this document type requires form-based submission instead of file upload
!
Attendance Module Not Available
Confirm you have an assigned company and supervisor
Verify your current application or proposal status
Ask your coordinator or instructor to review your assignment state
!
A Feature Is Not Visible
Some modules are role-based or condition-based
Recheck your logged-in role and active workflow status
