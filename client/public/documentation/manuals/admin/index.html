User Management
Create, update, deactivate, and remove user accounts for all roles.
/admin/users
Creating a new user
1
Go to /admin/users and click Create User
2
Fill in the user's name, email, and assign the appropriate role
3
Set initial account state (active/inactive)
4
Save — the user receives login credentials via email
User roles you can create
Student
Path: /student — OJT/internship students
Instructor
Path: /instructor — faculty supervisors
Coordinator
Path: /coordinator — program coordinators
Industry Partner
Path: /industry-partner — company supervisors
Admin
Path: /admin — platform administrators
Managing existing users
1
Search for the user by name, email, or role
2
Edit profile details, role, or account state as needed
3
Deactivate accounts to suspend access without deleting data
4
Remove users where permitted — this action may be irreversible
Prefer deactivating over deleting users. Deletion may remove associated records and cannot be undone.

Escalation Guide
How support issues reach the Admin level and what to do with them.
Escalation path to Admin
1
Student reports issue to their Instructor
2
Instructor attempts resolution or escalates to Coordinator
3
Coordinator attempts resolution or escalates to Admin
4
Admin resolves or routes to the Technical Team
What to collect from escalated reports
1
Full name and role of the affected user
2
Screenshot or recording of the issue
3
Date and time of occurrence
4
Module and page URL where the issue occurred
5
Expected behavior vs. actual behavior
For system-level bugs, always attempt to reproduce the issue in a controlled environment before applying fixes to production.
