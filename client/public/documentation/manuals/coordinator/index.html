Troubleshooting Guide
Common coordinator issues and resolution steps.
!
A student is not appearing in my student list
Check if the student is enrolled and their account is active
Verify the student has been assigned to an instructor in your program
!
I cannot see forwarded proposals
Check that the instructor has actually forwarded (not just reviewed) the proposal
The status must be FORWARDED_TO_COORDINATOR for it to appear in your queue
!
Report export is not working
Check your browser permissions for file downloads
Try a different browser or contact the Admin team
!
Supervisor did not receive their account email
Verify the email address entered when creating the supervisor account
Ask the supervisor to check their spam/junk folder
Contact the Admin team if the email needs to be resent
!
MOA upload is failing
Ensure the file is a supported format (PDF or document)
Check that the file size is within the allowed limit
Try refreshing the page and re-uploading
Escalation path
1
Try the troubleshooting steps above
2
Escalate to the Admin / Technical Team directly
