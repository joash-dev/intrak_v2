# 🚀 INTRAK Production Setup

## Quick Start

All production account setup files have been organized in the **`production-accounts/`** folder.

### 🎯 For Windows Users:

1. Navigate to the `production-accounts` folder
2. Double-click **`START-HERE.bat`** for one-click setup
3. Or run **`setup-production-accounts.bat`** manually

### 🐧 For Linux/Mac Users:

1. Navigate to the `production-accounts` folder
2. Run **`setup-production-accounts.sh`** for automated setup

### 📋 For Documentation:

- **`production-accounts/README.md`** - Complete setup guide
- **`production-accounts/QUICK-ACCESS-CARDS.md`** - Quick credential lookup
- **`production-accounts/production-accounts-summary.md`** - Detailed documentation
