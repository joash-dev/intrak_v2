## Getting Started

### System Requirements
- Modern web browser (Chrome, Firefox, Edge, Safari)
- Stable internet connection
- JavaScript enabled

### Accessing the System
1. Open your web browser
2. Navigate to the system URL
3. Enter your credentials (email and password)
4. Click **Login**

### First-Time Login
1. Use the credentials provided by your administrator
2. You may be prompted to change your password
3. Complete your profile information
4. Set up Two-Factor Authentication (recommended)

# 👨‍🎓 Student User Manual

## Overview
The Student Portal provides tools to manage your OJT/Practicum activities, track attendance, submit documents, and monitor your progress.

## Navigation Menu

| Menu Item | Description |
|-----------|-------------|
| 🏠 Overview | Dashboard with progress summary |
| 📄 Documents | Document submission and management |
| 📋 Templates | Download required document templates |
| 🏢 Company | Company selection and partnership assistance |
| ⏰ Attendance | Log and track your attendance |
| 📊 Evaluation | View your evaluations |
| 📝 Weekly Report | Submit weekly accomplishment reports |
| ⚙️ Settings | Profile and account settings |

---

## Features

### 1. Dashboard (Overview)
**Location:** `Overview` menu

The dashboard provides a quick summary of your OJT progress:

- **Progress Card**: Shows completed hours vs. total required hours
- **Document Status**: Summary of pending, approved, and rejected documents
- **Attendance Summary**: Recent attendance records
- **Upcoming Deadlines**: Important dates and submissions
- **Recent Activities**: Latest system notifications

**How to Use:**
1. Login to your account
2. You will automatically land on the Overview page
3. Review your progress statistics
4. Click on any card to navigate to detailed views

---

### 2. Document Management
**Location:** `Documents` menu

Upload and manage all required OJT documents.

#### Features:
- **Upload Documents**: Submit required documents (PDF, images)
- **Track Status**: Monitor approval status (Pending, Approved, Rejected)
- **View Feedback**: Read reviewer comments on rejected documents
- **Re-upload**: Submit corrected documents if rejected

**Supported File Types:**
- PDF documents
- Images (JPG, JPEG, PNG)
- Maximum file size: 10MB

#### How to Upload a Document:
1. Go to `Documents` menu
2. Click **Upload Document** button
3. Select the document type from dropdown
4. Drag and drop your file or click to browse
5. Add any notes (optional)
6. Click **Submit**

#### Document Statuses:
| Status | Description |
|--------|-------------|
| 🟡 Pending | Awaiting review |
| 🟢 Approved | Document accepted |
| 🔴 Rejected | Needs revision (check feedback) |

---

### 3. Document Templates
**Location:** `Templates` menu

Download official document templates required for your OJT.

**Available Templates:**
- MOA (Memorandum of Agreement)
- Training Plan
- Weekly Report Form
- Evaluation Forms
- Endorsement Letters
- Waiver Forms

**How to Download:**
1. Go to `Templates` menu
2. Browse available templates
3. Click the **Download** button next to the template
4. Fill out the downloaded form
5. Upload the completed form via Documents menu

---

### 4. Company Selection & Partnership Assistance
**Location:** `Company` menu

Browse and apply to partner companies.

#### Features:
- **Browse Companies**: View list of available partner companies
- **Company Details**: See company information, available slots, requirements
- **Apply to Company**: Submit application to preferred companies
- **Track Applications**: Monitor status of your applications
- **Partnership Assistance**: Request help finding a company (if needed)

#### How to Apply to a Company:
1. Go to `Company` menu
2. Browse the list of companies
3. Click on a company to view details
4. Check available slots and requirements
5. Click **Apply** button
6. Add a personal message (optional)
7. Submit application

#### Application Statuses:
| Status | Description |
|--------|-------------|
| 🟡 Pending | Awaiting instructor approval |
| 🟢 Approved | You are assigned to this company |
| 🔴 Rejected | Application not approved |
| ⚪ Withdrawn | You cancelled the application |

---

### 5. Attendance Tracking
**Location:** `Attendance` menu

Log your daily attendance during OJT.

#### Logging Methods:
1. **Manual Entry**: Enter time in and time out manually
2. **QR Code**: Generate QR code for supervisor/instructor to scan and verify

#### How to Log Attendance (Manual):
1. Go to `Attendance` menu
2. Click **Time In** or **Time Out** button
3. The system will record the current time
4. Add tasks accomplished (optional)
5. Your attendance will be sent for verification

#### How to Use QR Code:
1. Go to `Attendance` menu
2. Click **Generate QR Code**
3. Show the QR code to your supervisor
4. Supervisor scans to verify your attendance
5. QR code expires after 60 seconds

#### Viewing Attendance History:
- Use the calendar view to see past attendance
- Filter by date range
- Export attendance report (PDF/Excel)

#### Attendance Approval:
- Logged attendance is sent for verification
- Your supervisor or instructor will verify
- Approved attendance counts toward your hours

---

### 6. Evaluation
**Location:** `Evaluation` menu

View evaluations submitted by your instructor and supervisor.

**Features:**
- View evaluation scores and feedback
- Track performance over time
- See areas for improvement
- Download evaluation reports

---

### 7. Weekly Report
**Location:** `Weekly Report` menu

Submit weekly accomplishment reports.

**How to Submit:**
1. Go to `Weekly Report` menu
2. Select the week number
3. Enter the date range
4. Fill in:
   - Tasks Accomplished
   - Knowledge/Skills Learned
   - Challenges Faced
5. Save or Submit the report
6. Export as DOCX (optional)

---

### 8. Settings
**Location:** `Settings` menu (gear icon)

Manage your profile and account settings.

#### Available Settings:
- **Profile Photo**: Upload or change your profile picture
- **Personal Information**: Update name, contact details
- **Password**: Change your password
- **Two-Factor Authentication**: Enable/disable 2FA
- **Notifications**: Configure notification preferences
- **Theme**: Switch between light and dark mode

# 🔧 Common Features

## Profile Photo

All users can upload a profile photo:

1. Go to **Settings**
2. Click on your profile picture or **Change Photo**
3. Select an image file (JPG, PNG, GIF, WebP)
4. Maximum size: 2MB
5. Click **Upload**

## Theme (Light/Dark Mode)

Toggle between light and dark themes:

1. Go to **Settings**
2. Find **Appearance** or **Theme** section
3. Click toggle to switch between Light/Dark
4. Changes apply immediately

## Notifications

View and manage notifications:

1. Click the **Bell icon** in the header
2. View recent notifications
3. Click on a notification to see details
4. Mark as read individually or all at once

## Two-Factor Authentication (2FA)

Enable extra security:

1. Go to **Settings**
2. Find **Security** section
3. Click **Enable 2FA**
4. Scan QR code with authenticator app
5. Enter verification code
6. 2FA is now active

## Password Change

Change your password:

1. Go to **Settings**
2. Find **Security** or **Password** section
3. Enter current password
4. Enter new password (twice to confirm)
5. Click **Update Password**

## Help & Support

Access help resources within the application:

1. Go to **Settings**
2. Select **Help & Support** from the navigation menu
3. Available options:
   - **FAQs**: Quick answers to common questions
   - **Quick Guide**: Step-by-step guides for using the portal
   - **Privacy Policy**: Information about data handling
   - **Contact Support**: Email support at intraksystem@gmail.com

## About Us

Learn about the system and its developers:

1. Go to **Settings**

3. Available information:

# 🆘 Troubleshooting

## Common Issues

### Cannot Login
- Verify your email and password are correct
- Check if CAPS LOCK is on
- Try the "Forgot Password" option
- Contact your administrator if locked out

### Document Upload Failed
- Check file size (max 10MB)
- Verify file type (PDF, JPG, PNG)
- Ensure stable internet connection
- Try refreshing the page

### Attendance Not Logging
- Check your internet connection
- Verify you're within allowed time window
- Try refreshing the page
- Contact your instructor if issue persists

### Cannot See Assigned Students
- Refresh the page
- Logout and login again
- Verify students are assigned to you
- Contact coordinator if issue persists

### Page Not Loading
- Clear browser cache
- Try a different browser
- Check internet connection
- Try incognito/private mode
